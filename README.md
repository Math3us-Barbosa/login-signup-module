# login-signup-module

Monorepo do projeto de portfólio de autenticação para um grupo de
prestadoras de serviço.

- [`backend/`](backend/) — API Spring Boot (Java 21, Postgres, JWT).
  Convenções e regras em [`backend/CLAUDE.md`](backend/CLAUDE.md).
- [`frontend/`](frontend/) — aplicação React + Vite.
  Convenções e regras em [`frontend/CLAUDE.md`](frontend/CLAUDE.md).

**Fase atual:** só autenticação (cadastro e login). Nenhum outro requisito
foi levantado ainda.
